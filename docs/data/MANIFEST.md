# Data manifest

`docs/data/manifest.json` is committed. It is generated by:
```bash
.venv/Scripts/civicpulse manifest --verify-source-counts --out docs/data/manifest.json
```
(Code: `packages/ingestion/civicpulse_ingestion/manifest.py`.) It records, for every
ingestion run:
- the extraction start and end time
- the source version (`rowsUpdatedAt` when the run started)
- the exact `$where` clause
- rows fetched vs rows on disk
- the created-date range on disk
- the file count and bytes
- a **SHA-256 checksum**: sha256 over the sorted `file:sha256` lines of the run's raw Parquet
  pages

With `--verify-source-counts`, each bounded backfill window is **re-counted live** at Socrata
(`count(*)` with the same `$where`) and compared with the rows on disk.

## How the backfill is resumable
- `scripts/backfill_history.sh` (also `make backfill-history`) runs six half-year windows.
- Each window is its own run with `--skip-if-succeeded`, so a window that already completed with
  the same `$where` is skipped.
- A failed or interrupted window resumes from its checkpoint (keyset on `:id`).
- Pages are fetched with retries. One live HTTP 503 during the incremental run was retried
  successfully.
- Missing periods are never filled. A gap would show in `backfill_coverage.gaps_between_windows`
  and in `source_gap_dates` in the model outputs.
